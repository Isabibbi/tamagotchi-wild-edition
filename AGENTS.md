# Project-wide instructions

For every task and every session in this repository:

1. Load and follow the `i-have-adhd` skill located at:
   `.agents/skills/i-have-adhd/SKILL.md`

2. Apply that skill by default to all responses, planning, explanations,
   code-related communication, and agentic work.

3. Do not require the user to invoke `$i-have-adhd`.

4. Only disregard the skill when:
   - the user explicitly requests a conflicting format, or
   - a higher-priority instruction conflicts with it.
