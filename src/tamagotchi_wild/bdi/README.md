# Piani BDI

Questa cartella contiene i piani AgentSpeak dei ruoli operativi.

- `logistics.asl`: reagisce alla percezione di una ciotola vuota e crea la
  richiesta di alimentazione.
- `feeding.asl`: accetta il task, richiede le azioni all'ambiente e registra
  successo o fallimento.
- `veterinary.asl`: coordina trasporto di andata, trattamento e trasporto di
  rientro del paziente.

`logistics.asl` contiene anche i piani di trasporto medico per entrambe le
direzioni.
